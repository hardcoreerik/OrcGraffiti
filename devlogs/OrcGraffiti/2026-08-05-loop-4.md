## What was implemented

### PaintStateMerge (2 files)

Two merge policies for combining image-paint results with existing mmu_segmentation_facets:
- `PreserveExisting`: only paints faces currently kStateNone
- `OverwriteInsideMask`: overwrites any face the projection touches

### ImagePaintPipeline (2 files)

End-to-end headless pipeline: `ImagePaintRequest -> FacePaintPlan`.

Stages in order:
1. Topology fingerprint (FNV-1a-64 for stale-apply detection)
2. Per-face geometry (unit normals + areas for region cleaner)
3. sample_faces (FastCentroid / Gaussian7)
4. Build ColorSample list (weight = face_area * alpha)
5. quantize_colors (median-cut k-means)
6. match_clusters_to_filaments (CIEDE2000)
7. assign_to_cluster per face (CIE76)
8. clean_tiny_regions (optional)
9. merge_paint_states (policy)

Two overloads:
- `run_image_paint(request, cancel)` — decodes image from path first
- `run_image_paint(request, image, cancel)` — pre-decoded (for tests and preview cache)

### test_image_paint_pipeline (11 tests)

Merge policy unit tests (4):
- PreserveExisting leaves pre-painted faces alone
- OverwriteInsideMask replaces existing paint
- Empty proposed returns current unchanged
- make_blank_states correct length and zeros

Golden-cube integration tests (7):
- Top-down solid image paints only top face (states[2]==1, states[3]==1)
- Transparent image paints nothing
- PreserveExisting keeps pre-painted face, paints neighbour
- Diagnostics count painted faces and area
- Fingerprint is deterministic across two calls
- Empty mesh returns NoEligibleFaces error
- No filaments returns NoAvailableFilaments error
