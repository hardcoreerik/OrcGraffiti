## What Was Done

### Bug Fixes

1. **Redundant vertex-copy code removed** (`GLGizmoImagePainter::apply()`):
   - Previous code first pushed dummy `Vec3f{}` entries via the indices loop,
     then cleared and re-copied properly — the dummy push_back was dead but wasteful.
   - Replaced with a single clean reserve+push_back loop.

2. **Type mismatch fixed** (`stl_triangle_vertex_indices` → `Vec3i32`):
   - `stl_triangle_vertex_indices = Eigen::Matrix<int, 3, 1>` vs
     `Vec3i32 = Eigen::Matrix<int32_t, 3, 1>` — distinct Eigen types despite
     `int == int32_t` on all target platforms.
   - Added `.cast<int32_t>()` to ensure correct Eigen template instantiation.
