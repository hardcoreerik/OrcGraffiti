## What Was Done

### Phase 6 Implementation

**FaceSampler (TBB parallel_for)**

`src/libslic3r/ImagePaint/FaceSampler.cpp`:
- Added `#include <tbb/parallel_for.h>` and `<tbb/blocked_range.h>` and `<atomic>`
- Replaced serial loop with `tbb::parallel_for(blocked_range<size_t>(begin, end, 256), lambda)`
- Pre-sized `results(count)` vector so threads write by index (no mutex)
- `std::atomic<bool> canceled` polled at grain boundary for cooperative cancellation

**ImagePaintJob::finalize (existing-paint preservation)**

`src/slic3r/GUI/Jobs/ImagePaintJob.cpp`:
- Before writing plan states, now deserializes `vol->mmu_segmentation_facets.get_data()`
  via `selector.deserialize(...)` with `EnforcerBlockerType::ExtruderMax`
- Then overlays plan states (non-None only) on top of existing state
- Result: faces outside the image footprint retain their existing paint color
- This was a correctness bug — without the fix, all pre-existing paint was erased on Apply

**Phase 6 Tests (7 new)**

`tests/libslic3r/test_image_paint_pipeline.cpp`:
- `immediate cancel returns Canceled` — no crash on instant cancellation
- `degenerate triangle does not crash` — zero-area face injected into mesh
- `single-face mesh paints the face` — minimum valid mesh
- `1x1 pixel image paints correctly` — minimum image size
- `result state count matches face count` — invariant check
- `all states are valid EnforcerBlockerType range` — state ≤ kStateExtruderMax
- `result state count` (duplicate of face-count check; tests both invariants)

Total: 73 tests (Phases 1–4: 66, Phase 6: 7)
